# Local fonts

These Latin variable WOFF2 files are sourced from Fontsource 5.3.0 and loaded
with `next/font/local` from `src/app/layout.tsx`:

| Family | Fontsource package | Weight range | License |
| --- | --- | --- | --- |
| Inter | `@fontsource-variable/inter` | 300–900 | `OFL-Inter.txt` |
| Space Grotesk | `@fontsource-variable/space-grotesk` | 400–700 | `OFL-Space-Grotesk.txt` |
| JetBrains Mono | `@fontsource-variable/jetbrains-mono` | 400–700 | `OFL-JetBrains-Mono.txt` |

The Latin subset matches the previous Google Fonts configuration. Keep each
font's SIL Open Font License with its redistributed font files when updating
or replacing these assets.
